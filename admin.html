Messages

Ici vous préparez le texte qui sera affiché à tous les agents ou à tous les élèves. Comme cette version fonctionne sans serveur, après modification copiez le texte dans la variable messageGeneral du fichier concerné.

Guide de gestion

Agents : ouvrez agents/index.html, trouvez const agents = [...] et ajoutez chaque personne avec son code, nom, téléphone, fonction et photo.

Élèves : ouvrez cours/index.html, trouvez const students = [...] et ajoutez chaque élève avec son code et sa formation.

Photos : créez un dossier images à côté du fichier agents et placez les badges dedans. Le chemin doit correspondre au champ photo.

Messages : remplacez le contenu de messageGeneral dans le fichier concerné.

Important : les modifications faites dans cette page Admin ne sont pas enregistrées automatiquement sur GitHub. Le panneau sert de générateur pour préparer les données à copier dans les fichiers.
